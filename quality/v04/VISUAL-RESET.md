# FLUFF LAB v0.4 — 시각 검수

2026-10-19. 사용자 화면을 재구성했고 브라우저에서 검수했다. **레퍼런스와 동등한 최종 디자인 품질에 도달했다고 판단하지 않는다.** 기존 Blender 캐릭터 자산과 개발용 Character Studio는 보존했다.

## 반영한 내용

- Three.js 공간: 유리 기둥, 투명 받침, 링 구조, 라벤더 광층, 반사 바닥과 접촉 그림자. 기존 CSS 원형 장식을 제거했다.
- 사용자 화면: 데스크톱의 분리된 세로 카테고리와 하단 옵션 패널, 모바일의 가로 카테고리. 실제 backdrop blur, 여러 반사층, 유리 가장자리 하이라이트와 절제된 라임 선택광을 적용했다.
- 눈: 요청한 12종과 기존 Unimpressed를 포함한 13종, 크기 3단계. 반사 재질·곡선·홍채·하이라이트를 구별했다. 기본 스타일과 일시적인 표정 8종은 분리했다.
- 액세서리: 리본·안경·꽃·비니·별·헤드폰·왕관 7종을 실제 3D로 구성하고 한 개의 공유 Canvas에서 옵션 미리보기를 렌더링한다.
- 얼굴 주변 털 공간, 헤드폰 접촉 부위와 리본 장착 위치를 조정했다. 색상 전환·깜빡임·반응 애니메이션과 설정 저장을 유지했다.
- 털 프리셋은 기존 groom의 품질을 유지하도록 길이 0.94 / 1 / 1.08 범위로 제한했다. 독립적으로 제작한 세 종류의 groom은 아니다.
- 새 production dependency를 추가하지 않았다.

## 검증 결과

- TypeScript 검사, Expo web production export 성공.
- 기존 geometry·studio 테스트와 customization 테스트 통과. 눈 13종 × 표정 8종의 값 범위, 저장 데이터 검증, eyeScale 경계값을 검사했다.
- 브라우저 390×844 및 1280×800 화면에서 조작 패널과 얼굴의 겹침, 선택 반영, 스타일·표정 분리, 저장 후 복원을 확인했다.
- 눈 스타일 12종과 액세서리 7종의 정면/3/4 화면을 확인했다. 수정된 짧은 털·긴 털도 마지막 빌드에서 확인했다.
- 개발 스튜디오 경로가 계속 열리는 것을 확인했다. 최종 사용자 화면의 수집된 error 로그는 없었다.
- 별도 lint script는 없다. 실제 휴대폰·네이티브 앱·장시간 발열·context loss는 검증하지 않았다. 모든 몸체/털/눈/장식 조합의 미적 검수도 수행하지 않았다.

## 성능 관찰

Mac의 Codex 브라우저에서 390×844, DPR 최대 1.5로 측정했다. 모델 로딩 후 30프레임 준비, 180프레임 구간의 프레임 간격이다. GPU 단독 시간이나 실물 휴대폰 수치가 아니다.

반사 패스에서 고밀도 털을 중복 렌더링하지 않고 몸체·눈·액세서리 중심의 흐린 반사를 사용했다. 중앙 캐릭터 groom은 유지했다. 관찰값은 중앙값 16.6ms, p95 20.5ms, 약 135만 triangles/frame이었다. 이 샘플은 Sparkling Eyes, 기본 털, 장식 없음, 움직임 감소 상태였다. 이전 전체 털 반사 샘플은 중앙값 39.1ms, p95 43.5ms, 약 259만 triangles/frame이었으나 열린 탭 조건이 같지 않아 통제된 전후 벤치마크로 해석하면 안 된다. ## 레퍼런스 대비 남은 차이

1. 유리: blur·다층 하이라이트·투명 구조는 구현했지만, 레퍼런스의 복잡한 굴절과 풍부한 주변 반사까지 재현하지 못했다. 물리 기반 path tracing 결과가 아니다.
2. 조명: 캐릭터와 공간의 광색은 연결했지만, 받침과 배경의 반사광은 더 정교한 아트 디렉션이 필요하다. 라벤더 광층은 volumetric-like shader이며 실제 체적 산란은 아니다.
3. 캐릭터: 기존 풍성함은 유지했으나 레퍼런스처럼 정돈된 털 뭉침과 부드러운 재질 분리는 더 개선해야 한다. 특히 극단적인 털 길이 변화는 현재 자산에서 품질이 떨어진다.
4. 액세서리: 실제 입체 모델과 소재는 구현했지만 일부 접촉부와 장식별 정교한 마감은 추가 검수가 필요하다.

## 다음 개선 우선순위

- 반사광을 위한 전용 light card와 조명 배치를 제작하고, 유리 굴절의 품질/프레임 예산을 함께 조절한다.
- 받침의 하이라이트와 접촉 그림자를 더 자연스럽게 다듬는다.
- 독립적인 groom 프리셋과 장식별 접촉 영역을 제작하고 실물 모바일에서 LOD와 발열을 검증한다.

이번 결과는 재설계된 실시간 구현과 검수 자료이며, 최종 디자인 승인본은 아니다.
